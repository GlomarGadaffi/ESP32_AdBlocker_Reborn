Flash ESP32 AdBlocker Reborn

Install the DNS sinkhole firmware onto your board over USB, straight from this page. No toolchain, no downloads.

This browser can't talk to serial devices.

Flashing needs the Web Serial API, which today only Chrome, Edge, and Opera on desktop support — Firefox, Safari, and all mobile browsers do not.

Open this page in Chrome or Edge on a desktop, or flash from the command line with the esptool instructions in the README.

1

Connect your board

Plug it into USB, then pick its port in the browser prompt.

Close any serial monitor first.

On Windows a COM port can only be open in one program at a time. If idf.py monitor, PuTTY, the Arduino IDE, or a VS Code serial terminal has the port, connecting here fails with “Failed to open serial port”.

Confirm the board

Both supported boards are ESP32-S3 with 16 MB flash, so the chip alone can't tell them apart — the installed firmware's version tag can.

Picking the wrong one gives you a board that boots but can't drive its Ethernet chip. If you're unsure, check the silkscreen.
