What it is

Pi-hole proved that network-wide ad, tracker, and malware blocking belongs on a dedicated appliance instead of a brittle router bolt-on. This project takes that principle and swaps out the hardware underneath: it is a high-performance, native ESP-IDF C++ DNS sinkhole for ESP32-S3 + W5500 SPI Ethernet boards — a $15–$30 microcontroller doing the job traditionally delegated to a $50+ single-board computer, drawing under 1 Watt of wall power.

Running on constrained silicon does not mean running slow. This is a ground-up rewrite engineered for speed: it holds 800,000+ wildcard domains in external PSRAM, serves blocked verdicts and cached answers in ~1.8 ms at ~2,200 qps over a custom Layer-2 Ethernet fast path, and warm-boots its entire blocklist from an SD card cache in ~21 seconds after a power outage.

How it works

DNS queries never hit slow userspace socket stacks when they can be intercepted earlier. An L2 Ethernet tap catches UDP port 53 frames directly off the W5500 SPI interface, parses the DNS qname, runs a 40-bit Murmur3 hash lookup against the PSRAM domain table, and transmits the sinkhole reply (0.0.0.0) directly back to the physical wire.

Queries for legitimate domains bypass the sinkhole without penalty: the forward cache answers recurring lookups instantly, while misses are pipelined over encrypted DNS-over-TLS (DoT, port 853) to Cloudflare or Quad9, shielding your browsing from upstream ISP surveillance.

Quickstart

1. Flash the board: Connect your ESP32-S3 over USB-C and open the browser flasher (Chrome, Edge, or Opera on desktop). Choose your board model and flash in one click. No toolchain or IDF installation required.

2. Connect Ethernet & Power: Plug an RJ45 cable from your switch or router into the board. Power via USB-C or 802.3af PoE (LilyGO T-ETH-Elite). The board boots, obtains an IP via DHCP, and announces itself via mDNS:

https://esp32adblock.local   # LilyGO T-ETH-Elite
https://esp32adblock2.local  # Waveshare ESP32-S3-ETH

(No Ethernet? If disconnected, the board launches a temporary setup Wi-Fi network named ESP32AdBlock-Setup at https://192.168.4.1).

3. First-Boot Wizard: Open your browser to the local URL. Accept the self-signed ECDSA certificate warning, set your admin credentials, and verify your network configuration.

4. Protect your network: Log into your home router's admin panel, navigate to DHCP / LAN Settings, and set the Primary DNS Server to the IP address of your ESP32 AdBlocker. Reboot your router or renew device DHCP leases to protect your entire network instantly.

Features

  • 800,000+ wildcard domain capacity held in PSRAM as compact 40-bit Murmur3 hashes.
  • ~1.8 ms answer latency at ~2,200 qps on the L2 Ethernet fast path.
  • Fast warm boot in ~21 seconds from FAT32 MicroSD card cache (avoids 7+ minute download windows).
  • Encrypted Upstream (DNS-over-TLS) on port 853 with Cloudflare (1.1.1.1) and Quad9 (9.9.9.9) preconfigured.
  • Hägezi & OISD Feed Presets preloaded with de-duplication across multiple upstream feeds.
  • Instant Cache-Busting Whitelist & Rewrites: modifications bump the cache generation and apply immediately on the very next query.
  • Local LAN Rewrites: map local hostnames (e.g., nas.lan → 192.168.1.50) answered in <1 ms.
  • Client Access Control (ACL) & Bypass List: restrict resolver access to specific LAN IPs, or grant persistent unfiltered bypass.
  • Live Metrics & Monitoring: real-time counters, latency histograms, query logging (/log), and passive L2 LAN census (/census).
  • Signed OTA Updates: RSA-3072 firmware signature validation with hardware bootloader rollback failsafe.

Read this before you plug it in

  • Self-Signed TLS Certificate: The device generates a unique ECDSA P-256 certificate on first boot. The SHA-256 fingerprint can be confirmed over the USB serial recovery console (cert command) before proceeding.
  • Client ACL Behavior: The client access control list uses exact IPv4 matching (no CIDR). An empty list allows all clients; adding a single client restricts resolution exclusively to that IP, dropping queries from unlisted hosts.
  • Hash Collision Rate: Domains are compressed to 40-bit hashes in PSRAM. There is a theoretical 1-in-350,000 false-positive collision probability. Whitelist entries take precedence immediately without rebooting.
  • Emergency Serial Console: If admin credentials or network settings are misconfigured, plug in USB-C at 115200 baud to run admin-reset, cert-reset, wifi, or pause.
